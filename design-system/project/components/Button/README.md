Botão em pílula para as ações do site. Fonte: `assets/css/components/button.css` e `nav.css`.

- `.btn.btn-solid`: ação principal de um bloco, uma por vez. `accent-ink` sobre `accent-surface`; no hover um plano `text` sobe e o texto vira `bg`.
- `.btn.btn-line`: ação secundária ao lado da sólida. Borda `line-2`; no hover preenche com `accent-surface`.
- `.pill-btn`: chamada compacta da navegação, em mono caixa alta.
- `.icon-btn`: círculo de 38px com um ícone de traço de 16px; sempre com `aria-label`.

Você fornece o rótulo (verbo curto, caixa normal: "Ver projetos") e, se a ação leva a outro lugar, a seta `.arr` depois do texto. Não empilhe dois botões sólidos nem use o sólido para links de texto.
